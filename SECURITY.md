# Security policy

Report a vulnerability in this fork privately by email to
[security@latere.ai](mailto:security@latere.ai). Do not open a public issue
or pull request for it.

Include the release you tested (`mc --version`), the steps to reproduce, and
the impact you observed. A vulnerability in code inherited from upstream
belongs here too: upstream `minio/mc` is archived and no longer accepts
reports.

Fixes ship in a new release of this fork, `ghcr.io/latere-ai/mc`, and the
release notes name the issue. Only the latest release is supported.
